## 研究问题及去重

在同一场所、相同 BTC/ETH 固定内部比例和共同事前风险起点下，按已完成价格波动调整总仓位，能否在成本后改善收益与风险的取舍？这是配置/风险控制问题，不预设方向预测、独立 alpha 或不亏损。

- B V3 的 84 日自身方向信号决定是否入场；本建议没有方向信号，风险袖套始终为 50% BTC、50% ETH，未配置部分留作现金。
- 旧 C 的 `MIN_1_PRIOR_252_MEDIAN_SIGMA20_OVER_CURRENT_SIGMA20` 已属波动缩量家族；本建议不是新发现的机制。差异是剥离趋势/反转入场，以固定两币组合的含协方差波动调整总配置，并用一次前置校准取代旧 C 的 252 日滚动中位数、273 日依赖和恢复步长。不能将这些工程差异写成经济独立性。
- Issue 141 的小时响应规则已 `STOP_RULE_NOT_SUPPORTED`。本建议不改变其持有期、信号阈值或结论，也不为它续跑。

### 因果规则与公平对照

令 `x_d = 0.5*r_BTC,d + 0.5*r_ETH,d`，`sigma_t = sample_std(x_最近20完整日, ddof=1)`，不年化。等价于使用相同窗口样本协方差矩阵的 `sqrt(w'Σw)`，包括交叉协方差，不能假设两币独立；这是固定权重风险代理，不是假装每日无成本再平衡的可交易收益。

以前述校准窗口算 `sigma_0`，一次冻结 `tau=0.40*sigma_0`。V 的每周目标总仓位为 `min(0.80, tau/sigma_t)`；F 每周固定总仓位 `0.40`。各自将目标一半分给 BTC、一半分给 ETH。两者第一次目标同为 40%，同用 1000 USDT 起始模拟现金；余款零利息，不做稳定币收益或借贷。20 日、50/50、40/80% 和周频均不再拟合。

每周一 00:00 UTC，只使用截至周日结束的 20 个日收益，排队在周一 01:00 UTC 可用小时开盘执行，明确一小时迟延。目标数量按决策时已知 NAV/价格确定，成交时先卖后买；现金不足则所有买单同比缩小，禁止透支。目标每币≤40%、总≤80%，实际价格和买入扣 base 手续费使成交后比例偏离目标，必须报告。每个共同可观察小时风险检查发现每币40%或总80%漂移越界时，冻结只减仓目标，在下一可用开盘纠偏，不能增仓。先逐币上限裁剪，再按总上限同比缩减；不同币有开盘即可各自执行，缺开盘继续保留减仓队列。跳空暂时越界照实记录，不能承诺连续不越界。周内不为追踪 50/50 主动再平衡，风险事件除外。

F 也是每周再平衡的固定配置，并非无交易成本的买持。F 与 V 的资产、时钟、价格可用性、成本及风险覆盖层完全相同，但各自按自己的 NAV 触发风险事件。共同起点是事前风险锚，不是全期间已实现风险匹配。禁止用最终平均暴露/波动反推 F 权重、全样本缩放、事后最优组合或把 V 降低仓位本身当作优势。

### 风险、异常与成本

- 每个完整小时收盘更新各自成本后 NAV 与不重置的高水位。首次观察到 DD≥10% 时永久锁定风险乘数 0.5，并在下一可成交小时减仓至不超过减半目标；DD≥15% 永久禁止增加任何资产数量，允许减仓。阈值只改变未来交易，不能按触发价回填成交。任一路径观测 DD≥20% 时共同截断 cohort 的正常决策，记录共同触发时点及各路径自身 10/15/20 状态。协调器排队管理性退出，只有窗口内后续真实存在的各币开盘才可模拟卖出并计费，直到四路径库存清零或到原终点；无开盘则保留库存及 UNKNOWN，不向窗外取价。报告触发时点、结算结束时点和实际处理区间，不能说完成全部2021–2022，也不能从 F 触发推论 V 自身越线。这是研究管理停止，不是候选可观察另一个虚拟钱包的交易信号。
- 用户 20% 是验收上限；10/15 是前置约束，均不是限损保证。波动突变、相关性骤升、估计滞后、小时内价格路径及执行跳空都可能越线；记录小时收盘观测 DD 和越线，真实连续 DD 保持 `UNKNOWN`。不能把年化波动目标当成 20% 回撤约束。
- 严格沿用 V3 已注册的 13 缺小时、4 短小时、7 不完整日的逐币精确时间及语义，禁止退回只有单日异常的旧规则。缺失日使所需 20 日窗口无效，不压缩日历、不补零或填收益；该次周调仓取消，不延期择时。未注册异常立即 `BLOCKED_DATA`。短小时不能生成完整信号，但已验证存在的开盘是否能执行，依 V3 原合同判断。
- 无完整估值时保留持仓与现金账，不把陈旧 NAV 当成已观测价格；恢复前禁止新买，本次固定恢复规则要求连续 3 个两币完整小时检查（是本次建议，不冒充旧 V3 合同），仍不补做错过的周调仓。完整的 20 日窗口在下一正常周一才允许调仓。需逐项报告未知估值时段和跨缺口持仓；无法界定其风险时，风险合格结论为 `UNKNOWN`，不可用可见 DD 通过硬门槛。
- 两成本世界独立现金/数量账：base 每边手续费 0.001、滑点 0.0006；stress 每边 0.002、0.0012。买价为开盘×(1+s)，卖价为开盘×(1−s)，买费从购入 base 数量扣除，卖费从 quote 收益扣除；首笔建仓、周调仓及实际模拟风险退出全部收费，终点仅另列估算退出成本。目标数量按决策 NAV/价冻结为交易前数量，买入后净数量扣买费，因此首次实际权重按成本分别低于共同40%目标，不以无费收益路径校准。无永续 funding。它们是保守预筛假设，非声称已核实账户费率。
- 预筛可使用高精度分数数量，必须明确交易所步长、最小金额及实际成交容量尚未验证，忽略 lot/tick/dust 通常偏乐观，因此不是可交易性验收。不得让不足最小额的假定成交被解释成真实执行证据。

### 有限预算、报告及停止

建议一次市场分析调用，固定 `V/F × base/stress = 4` 条路径，单工作者、墙钟 180 秒、重试 0、市场 HTTP 0、native 0、全局登记 0。代码与合成验证已由上述监督评论授权，必须先完成并固定后再读价；失败消耗本次市场调用，禁止凭结果调整参数、换窗或扩展研究域。输出只存外部运行根，Git 仅可收经核验的摘要。

必须并列报告四路径：成本前后收益、净 USDT、观测及未知 DD、实际平均/最大暴露、现金比例、成交额/换手/成本、周决策有效与取消数、10/15/20 事件、缺口持仓时长，以及固定 2021/2022 年分解。年度分解只作描述，不参与选择；不能把小时数、周次数当独立样本数。本最小实现不计算 Sharpe。成本前诊断仅为同条实际路径 mark NAV 加回每笔成交参考价计值的 base/quote 费用和滑点损失，未计机会成本或复利路径变化，不是另一条无成本策略，不新增第五路径。月/年 MTM 是实际共同区间内首末观察 NAV 差，跨缺口只在后续恢复价反映，未知时段独立列出，不以日历年名声称全年已完成。

事前裁决顺序：数据/执行无法核验为 `BLOCKED_DATA`；持仓缺口导致真实风险不可判为 `RISK_UNKNOWN_NO_QUALIFICATION`；观测越过 20% 为 `STOP_RISK_LIMIT`。完整风险证据下，仅当 V 在两个成本世界均净收益非负，且相对 F 的净收益不低、观测 DD 不高、至少一项严格改善，才标注 `DESCRIPTIVE_PARETO_SUPPORT_ONLY`。这是严格的预筛取舍门槛，不是显著性或样本外证明。其余为 `STOP_NO_JOINT_SUPPORT`，如仅 DD 下降而收益下降，明确“减少风险同时放弃收益”，不命名为更优。全现金或零有效调仓不能作为机制支持。

已知旧源存在缺口，必须预期风险资格可能终止为 UNKNOWN；允许有限开发描述，不为追求资格反复清洗、删时段或补采。任何后续独立确认均需新的单独决定，本文不自动启动 forward、另一个候选或下一研究域。
