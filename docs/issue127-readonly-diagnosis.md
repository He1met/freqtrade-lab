## 3. 1000 USDT cell 与 native padding 的定量约束

固定 assembly：BTC minQty/step=0.001、minNotional=50；ETH minQty/step=0.001、minNotional=20。原生 fresh-entry 传 stop_arg=-0.05，调整回调传-0.1，调整入场传0；reserve默认0.05。不是策略哨兵 stoploss=-0.99。1x 时：

`native_min = max(minNotional × clamp(1.05/(1-|stop_arg|),1,1.5), minQty × open × 1.05)`。

BTC示例（A-trend 2024-08-06 01:00，原open56010.1）：核心1lot为56.0101 USDT，native最小值58.810605；下一完整lot台阶为0.002 BTC=112.0202 USDT。修正预留端点只能保留原1lot，不能为了 native 门强行凑成2lot。此前合成 BTC price=100 的例子里，minNotional分支主导；真实价格下 minQty×price×1.05 常主导，不能借合成通过证明当前资金单元可执行。

## 4. 旧路径自然簇：支持归属不等于独立

使用完整原逻辑区间，不裁短到实际部分持仓。候选必须自然退出（stop/expiry/signal）且有区间内同方向实际增仓和正有效意图。认证还要求一个真实已闭合cycle在该episode内开仓、恰在自然退出时平仓，且该cycle每小时只有这个family意图。不是家族PnL/lot所有权分配。不能认证的候选保留模糊，不为变紧删掉。

| 每条base或stress路径 | trend正式计数 / 上界 | reversal正式计数 / 上界 | 说明 |
|---|---|---|---|
| A-trend | 1 / 1 | 未启用 | ETH完整到期周期 |
| A-reversal | 未启用 | 2 / 2 | 第3个实际cycle是BTC边界截断，不计自然簇 |
| B | 1 / 1 | NULL / 1 | reversal与其他意图净额相互作用，不能完整唯一认证 |
| C | 1 / 1 | NULL / 1 | 同上，不因实际有3个cycle填成3个家族样本 |
| half-risk-B | 0 / 0 | NULL / 1 | trend无合格的实际增仓支持；不是缺数据填0 |

上界的映射证明：冻结定义下任何真实合格区间都有区间内的兼容增仓，因此必在候选集。对任一真实支持子集，每个簇选一个原区间作为代表；跨资产同方向重叠/touching合簇，故代表之间必须严格不重叠。最早结束贪心得到的最大严格不重叠候选集合，界定这些代表的数量。已验证完整小时映射和每资产/family唯一活跃episode；另列更宽的真实增仓事件数量界。若端点/映射缺失，入口失败而不输出伪上界。不能直接拿全模糊候选集合的合簇数做上界，因为模糊桥接区间可能把两个真实簇错误合成一个。

正式计数或区间不重叠都不认证统计独立；10条同源路径不合并计数。结果最多 UNDERPOWERED，30门和真实经济资格仍未满足。上述上界**只针对有实现缺陷的旧执行路径**，不能推断修复后仍只有这些样本，也不能外推61日后片或独立确认。
