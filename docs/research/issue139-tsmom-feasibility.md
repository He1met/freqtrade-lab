- continuation-v2更换为 `[2023-11-01,2025-01-01)`，不是续补旧历史。其收据记录两币各10248 trade小时、10248 mark小时、1281 funding事件且关联mark完整；这证明该收据对应新窗口结构，不补旧窗口。

## B主检验与样本结论

先完成共享技术可执行性、来源、cost、lot和风险语义准入。技术/模型/控制完整性失效阻断依赖调用；某模式实际违反风险线判该模式失败，不能自动推断其他模式违反同一线。经济净亏与技术失效分开。

获未来市场授权后的拟议训练顺序：B base/stress → A-BTC base/stress → A-ETH base/stress → C base/stress → half-B base/stress，共10次。B事先指定，不因A亏损删币或改规则，也不因C更好换主候选。有效负结果不停止固定诊断批次；共享实现缺陷则停止。A各1000USDT独立，不能拼接成B；B/C/half-B各自共享一个1000钱包。C仅作为动态减风险与固定half-B的诊断对照，未建立统计合同前不宣称显著增量。

预算 `28已占 + 10旧sealed + 10拟议训练 + 48未分配 = 96`，本轮新占槽0。撤回v1的10次前向分配，不冻结前向日期。

84日回看和持仓上限不能推导依赖长度；730日里能分出8个84日块只是日历算术。12块、30合并episode、三年日历均无本轮功效论证，不能作为资格门或已确认期限。旧Issue131的30cluster门与UNDERPOWERED不变，新研究需另论证自然样本、跨币依赖、精度/功效与成本后不亏置信下界。短期训练可回答执行/成本路径和诊断问题，不能取得独立资格；未来必须先冻结有依据的统计合同、合法warmup和有限停止日历，再读独立数据。不够信息可以终止UNDERPOWERED，不调短回看、不延长到满意。
