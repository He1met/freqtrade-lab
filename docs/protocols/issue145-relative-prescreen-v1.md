# Issue 145 单次相对强弱开发预筛执行协议 v1

监督推进依据：https://github.com/He1met/freqtrade-lab/issues/145#issuecomment-5584004142 。这是已有研究授权内的一个开发实验，不是新交易、采购或用户风险授权。原机制卡 `docs/discovery/issue145-relative-strength-allocation-v1.md` 的 `PROPOSAL_ONLY` 保留为历史，本协议与执行代码、manifest在读行情前一起固定。版本 `ISSUE145_RELATIVE_PRESCREEN_V1`。

## 固定问题、规则与对照

只检验一个28日相对强弱配置R，与固定E/B/H比较；均为Binance BTCUSDT/ETHUSDT SPOT，初始1000 USDT现金，禁止借贷、short、利息、funding、动态波动目标及其他候选。基准顺序BTC/ETH。

- 每周一00:00 UTC，用严格连续29个完整UTC日收盘，计算 `Q=(ETH_last*BTC_first)/(ETH_first*BTC_last)`，跨度28日。所有中间日也须完整，不能只取两个端点绕过缺口。Decimal精度50，无四舍五入阈值。
- R：Q>1配10%/30%，Q<1配30%/10%，Q=1配20%/20%；E永远20%/20%；B永远30%/10%；H永远10%/30%。总目标40%，剩余现金；风险层可减少配置。三个对照是事前固定的对称控制，不从中选择另一个策略。
- 每个成本世界有R/E/B/H四个独立现金、数量、峰值和风险状态，八路径共享同一读取后的来源。固定总名义比例不代表已实现风险匹配。结果不反馈参数、日期或对照。

每小时顺序：到周一00边界，先使用上一个完整小时收盘NAV和Q冻结目标数量；本小时open执行此前风险减仓，其后执行已经到期的周单；最后读取该小时完整close更新风险。00点生成的周单只在01点open执行。执行数量根据00点已知NAV/价格冻结，卖出多余量后，买单根据实际open含滑点价格所需现金同比缩小。买费扣除后净数量会小于购入数量，但价格迟延可能使实际比例高于目标，不能承诺实际首仓低于40%。

事件明确区分：交易`utc`为open时间；风险/mark同时带`bar_open_utc`与`close_known_utc=bar_open+1h`；未知小时有`close_due_utc`，不伪称已知；周单有`decision_utc`、`last_signal_close_known_utc`及`execution_due_utc`。月/年归属按被观察bar所属期间，报告同时列出实际close可知时间。

## 费用、执行与风险

base每边fee=0.001、slip=0.0006；stress为0.002/0.0012。这是固定研究成本假设，非账户费率验证。买价open×(1+s)，现金减gross_qty×买价，base到账gross_qty×(1−f)；卖价open×(1−s)，现金入qty×卖价×(1−f)。先卖后买，无负数量/现金。初始、再平衡、风险与cohort行政退出全部收费；lot/tick/dust/最小订单不实现通常偏乐观，不能获得真实执行资格。

20%是用户硬回撤上限；以下10/15及40/80为沿用研究设计门，非新增用户指定：

- 按各自完整小时close成本后NAV，峰值只上调不重置。首次DD≥10%永久锁存0.5风险乘数，依最近有效的各币配置比例计算减半数量，只排队卖出，不补买；后续周目标也乘0.5。
- 首次DD≥15%永久禁止增加任何币数量，仍可减少；已有周单执行前检查此锁存。风险减仓若在同一open执行，取消该周单，防止卖后马上买回。
- 观察到单币市值>40%NAV或总市值>80%NAV时，先逐币裁剪到40%，必要时再共同缩至80%，冻结只减仓数量，下一各币可用open卖出，缺open继续排队。跳空、小时内走势及价格变化可暂时超限，记录而不回填触发价成交。
- 任一路径DD≥20%共同截断正常决策。记录共同trigger的bar-open及close-known、自身触发路径和每钱包10/15/20状态；协调器取消周单并排队所有钱包行政退出。仅原域内已有后续open可模拟卖出，直到八钱包清空或原终点；无价保留数量/UNKNOWN。行政退出不是R观察其他钱包的可交易信号，不从对照触发推论R自身失败，不把截断后缺少的年份充成全年。

## 异常与终点

39源SHA逐一校验（在唯一attempt内）；完整V3 inventory按逐币精确13缺小时、4短小时及7不完整日比对。未登记异常、SHA漂移、非法OHLC、重复时间或初始窗口失败为BLOCKED_DATA，消耗attempt，禁止补采/重跑。全域只读SHA与异常核验不增加一条经济路径。

任一币29日窗口无效，四种配置同时取消该周决策，不压缩日历、不补收益、不顺延找周；周执行缺任一open则整个周单取消，不补做。单币已存在的短小时open依V3仍可执行，但短小时不能产生完整close/日信号。风险减仓分币等待可用open。

共同完整估值缺失时，持仓/现金账不变，不向正常marks写陈旧价；记录未知小时与是否持仓，恢复前禁止买入。连续3个两币完整小时检查后恢复（本次固定设计），仍需下一正常周一且29日完整方可调仓。已知持仓缺口和小时内未观测风险使真实连续DD保持UNKNOWN，不能用小的观测DD通过20%资格门。

终点不成交：保留模型实际数量/现金，用最后共同已观察价格计算mark NAV，明确该价时间；另估若按该参考价退出的滑点和卖费，输出`mark_less_estimated_exit_cost`，不改数量、现金或成交ledger。若行政退出已经归零，估算退出成本自然为0。未观察终点价格/待退出库存不转换成0。
